# TorrentX UI standards & polish plan

**Goal** — Give TorrentX one enforceable visual language (spacing, radii, type, icon sizes, contrast) instead of ~13 ad-hoc spacing values and 7 icon sizes, so every screen looks deliberate and WCAG-legible in all 19 themes.

## Current context / assumptions (measured, 2026-10-22)

Repo: `~/projects/torrentx`, HEAD `f6a3ad4`, Rust 2021, egui/eframe 0.36.2.
UI code: `src/ui/{mod,header,search,results,favorites,rss,about,widgets}.rs` (3,181 lines),
main window wiring in `src/main.rs`, palette in `src/themes.rs` (`Pal`, 19 themes).

Baseline facts gathered from the tree (these are the defects the plan removes):

| Kind | Today | Count |
|---|---|---|
| `add_space()` literal values | 2, 3, 4, 5, 6, 8, 10, 12, 14, 20, 24, 40 | 13 distinct values, ~130 calls |
| Corner radii | 4, 5, 6, 10, 14 (+ `CornerRadius::same(4/5/6)`) | 6 distinct |
| Icon sizes passed to `svg_icon` | 8, 9, 10, 12, 13, 14, 15 | 7 distinct |
| `Margin::symmetric` | (5,1) (6,2) (7,2) (8,3) (9,4) (10,8) (14,8) (24,16) | 8 distinct |
| `pal.dim` text contrast (WCAG) | 1.92–3.36 : 1 — **fails AA 4.5** in every theme | all 19 |
| `pal.sub` text contrast | 3.98 : 1 in One Dark (others 5.0–8.1) | 1 failing |
| Table cell left inset | 4 px (text nearly touches the cell edge) | — |

Verified contrast samples: TokyoNight bg `#1a1b26` → text 10.59, sub 8.10, dim **2.76**;
OneDark bg `#282c34` → sub **3.98**; Midnight dim **1.92**.

Assumptions:
- No lib target (`src/main.rs` only) and everything is `pub(crate)`, so **tests must live in
  `#[cfg(test)] mod tests` inside the module** — `tests/*.rs` integration binaries cannot see
  these types.
- Screenshots are taken the way already proven on this box: KWin scripting activates the
  window, `xdotool` drives input, `import -window` captures, `tesseract`/PIL verify.
- No new dependencies. Design tokens are plain `f32` consts; contrast math is stdlib.

## Architecture / approach

1. `src/ui/tokens.rs` becomes the single source of truth: a 4-px spacing scale, 3 radii,
   4 icon sizes, one motion duration. Every UI file imports it via the existing
   `pub(crate) use ...` re-export in `src/ui/mod.rs`.
2. Legibility is **enforced at palette construction**, not by hand-editing 19 themes:
   `Pal::from` clamps `sub`/`dim` toward `text` until WCAG AA (4.5:1) passes, and a unit test
   iterates `Theme::all()` to prove it.
3. A shell gate (`scripts/ui-standards.sh`) fails CI on new magic numbers in `src/ui/`, so the
   standard does not decay. Visual results are proven with screenshots + pixel measurements,
   never eyeballed.

```rust
//! Design tokens: the only place spacing/radius/icon/motion numbers live.
//! Rule: 4 px grid for space, 3 radii, 4 icon sizes. Enforced by
//! `scripts/ui-standards.sh` (no numeric literals elsewhere in `src/ui`).

/// Vertical/horizontal rhythm. Use the nearest step, never a literal.
pub(crate) const SP1: f32 = 2.0; // hairline (inside a badge)
pub(crate) const SP2: f32 = 4.0; // label to its control
pub(crate) const SP3: f32 = 8.0; // items in a group
pub(crate) const SP4: f32 = 12.0; // groups in a row
pub(crate) const SP5: f32 = 16.0; // sections
pub(crate) const SP6: f32 = 24.0; // page padding
pub(crate) const SP7: f32 = 32.0; // empty-state block

/// Corner radii: inputs/buttons, panels, dialogs.
pub(crate) const R_SM: f32 = 4.0;
pub(crate) const R_MD: f32 = 8.0;
pub(crate) const R_LG: f32 = 12.0;

/// Icon box sizes. Stroke is 2.0 in every SVG (see assets/icons/README.md).
pub(crate) const ICON_XS: f32 = 10.0; // inline status glyph
pub(crate) const ICON_SM: f32 = 12.0; // button glyph beside text
pub(crate) const ICON_MD: f32 = 14.0; // toolbar / row action
pub(crate) const ICON_LG: f32 = 16.0; // header, empty state

/// Table cell inset — text must not touch the cell edge.
pub(crate) const CELL_PAD_X: f32 = 10.0;
/// Row hover/selection transition.
pub(crate) const MOTION_MS: u64 = 120;

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn space_scale_is_a_4px_grid() {
        for v in [SP1, SP2, SP3, SP4, SP5, SP6, SP7] {
            if v == SP1 {
                continue; // hairline step is the intentional exception
            }
            assert_eq!(v % 4.0, 0.0, "{v} is off the 4px grid");
        }
    }

    #[test]
    fn icon_sizes_are_ordered_and_smaller_than_their_row() {
        assert!(ICON_XS < ICON_SM && ICON_SM < ICON_MD && ICON_MD < ICON_LG);
        assert!(ICON_LG <= 16.0, "icons larger than 16px crowd a 28px row");
    }
}
```

### T2 — Enforce AA contrast in the palette (10 min)

In `src/themes.rs`, add above `impl Pal`:

```rust
/// WCAG 2.1 relative luminance of an sRGB colour (0..1 channels).
fn rel_lum(c: Color32) -> f32 {
    let ch = |v: u8| {
        let s = v as f32 / 255.0;
        if s <= 0.039_28 {
            s / 12.92
        } else {
            ((s + 0.055) / 1.055).powf(2.4)
        }
    };
    0.2126 * ch(c.r()) + 0.7152 * ch(c.g()) + 0.0722 * ch(c.b())
}

/// WCAG contrast ratio between two opaque colours (1.0 ..= 21.0).
pub(crate) fn contrast(a: Color32, b: Color32) -> f32 {
    let (x, y) = (rel_lum(a), rel_lum(b));
    let (hi, lo) = if x > y { (x, y) } else { (y, x) };
    (hi + 0.05) / (lo + 0.05)
}

/// Blend `c` toward `toward` in 2 % steps until it reaches `min` contrast on
/// `bg`. Returns `c` unchanged when it already passes (most themes).
fn ensure_contrast(bg: Color32, c: Color32, toward: Color32, min: f32) -> Color32 {
    if contrast(bg, c) >= min {
        return c;
    }
    let mix = |k: f32| {
        Color32::from_rgb(
            (c.r() as f32 * (1.0 - k) + toward.r() as f32 * k).round() as u8,
            (c.g() as f32 * (1.0 - k) + toward.g() as f32 * k).round() as u8,
            (c.b() as f32 * (1.0 - k) + toward.b() as f32 * k).round() as u8,
        )
    };
    for step in 1..=50 {
        let m = mix(step as f32 / 50.0);
        if contrast(bg, m) >= min {
            return m;
        }
    }
    toward
}
```

Inside `Pal::from`, immediately before returning `p` (find the `p` binding, keep the accent
override that follows it), clamp the two text tiers:

```rust

    p.sub = ensure_contrast(p.bg, p.sub, p.text, 4.5);
```

```rust
}
```

### T7 — The standards gate (10 min)

New file `scripts/ui-standards.sh`:

```sh
#!/bin/sh
# Fails when a UI file hardcodes a spacing/radius/icon size instead of using
# src/ui/tokens.rs. Deliberately textual: cheap, and it names the offending line.
set -eu
cd "$(dirname "$0")/.."
status=0
check() {
    hits=$(grep -rnE "$1" src/ui src/main.rs | grep -v 'src/ui/tokens.rs' || true)
    if [ -n "$hits" ]; then
        echo "FAIL: $2"
        echo "$hits"
        status=1
    fi
}
check 'add_space\([0-9]' 'literal add_space (use SP1..SP7)'
check 'corner_radius\([0-9]|CornerRadius::same\([0-9]' 'literal radius (use R_SM/R_MD/R_LG)'
check 'svg_icon\([^)]*, (8|9|10|11|12|13|14|15|16)\.0' 'literal icon size (use ICON_*)'
check 'Margin::symmetric\([0-9]+, [0-9]+\)' 'literal margin (use SP* pairs)'
[ "$status" -eq 0 ] && echo "ui-standards: ok"
exit "$status"
```

Run against the current tree *before* migrating to prove it bites:

```sh
# expect: FAIL: literal add_space (use SP1..SP7) + a list of lines, exit status 1
```

## Risks / tradeoffs / open questions

- **Snapping 6→8 and 10→12 changes density slightly.** Accepted: the current mix is what looks
  accidental. `ROW_HEIGHT_*` in `config.rs` is untouched, so row height stays a user setting.
- **Contrast clamp shifts `dim` visibly lighter** (TokyoNight `#565f89` → ~`#7e88ad`). That is the
  point (hints become readable); if a theme looks washed out, raise the clamp to 4.6 rather than
  special-casing a theme.
- **The grep gate is textual.** It cannot see a token passed through a variable, and it will need
  a one-line exemption if a legitimately odd value appears — add the exemption in
  `scripts/ui-standards.sh`, never in the screens.
- **Screenshot assertions are sample-based**, not a full visual regression (no baseline images to
  maintain). If drift becomes a problem, add `tests/screens/` baselines then — YAGNI today.
- Open question: should the selected-row accent bar use `pal.accent` or a 60 % tint of it? Start
  with full accent (highest contrast), revisit after seeing both screenshots.

**DoD**: gate green, `./scripts/ui-standards.sh` prints `ui-standards: ok`, T8's four assertions
pass in dark and light, screenshots committed, GUIDE/CONTRIBUTING describe the rules.
