MODIFIED-VERSION STATUS (OFL condition 3)
A subset is a Modified Version, and condition 3 forbids a Modified Version
from using a Reserved Font Name. These faces declare none: their copyright
string is exactly "© 2014-2021 Adobe (http://www.adobe.com/).", and the
upstream licence shipped with Noto Sans CJK (notofonts/noto-cjk,
Sans/LICENSE) is the plain OFL text with no reserved name filled in.
Condition 3 therefore does not restrict this subset, and the family names
"Noto Sans CJK JP" / "Noto Sans CJK KR" are kept unchanged. "Noto" is a
Google trademark used here descriptively, not a licence restriction.

HOW THE SUBSETS WERE MADE (reproducible)
  pyftsubset NotoSansCJKjp-Regular.otf \
    --unicodes="U+4E00-9FFF,U+3000-303F,U+3040-30FF,U+31F0-31FF,U+FF00-FFEF,U+2010-205F" \
    --layout-features='' --no-hinting --drop-tables+=BASE,VORG,vhea,vmtx
  pyftsubset NotoSansCJKkr-Regular.otf \
    --unicodes="U+AC00-D7A3,U+1100-11FF,U+3130-318F,U+A960-A97F,U+D7B0-D7FF" \
    --layout-features='' --no-hinting --drop-tables+=BASE,VORG,vhea,vmtx

Vertical-layout tables (BASE/VORG/vhea/vmtx) are dropped because egui renders
horizontally only; hinting is dropped for the same reason. Glyph coverage is
asserted in `src/app.rs` (`font_tests`) so a regenerated subset cannot ship
with a script silently missing.
